# CPongC

Pong clone written in C and SDL3.

It requires GCC and SDL3.



All the credits and a huge thank you for SDL3 go to the defunct Loki Software and all the development team.
Music: Interstellar Odussey, by Patrick de Artega -> https://patrickdearteaga.com/en/royalty-free-music/

## Controls

Player 1 moves with E and D, player 2 moves with the directional arrows Up and Down.
(I used E and D because they are in the same position on both AZERTY, QWERTZ and QUERTY keyboard). I do not have at the moment any plan to support other keyboard layouts.

## Build instructions

In order to build the project on Linuc, run from the main folder:

$ make all

Instructions for Windows will follow soon.
